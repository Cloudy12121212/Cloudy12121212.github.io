# Organization marks

The Cheyun custom icon has been removed from the profile and is no longer displayed. Other marks are served locally from `public/logos/`, configured in the bilingual profile entries in `backend/content.py`. Decorative images have empty alt text because the adjacent organization name supplies the accessible label. Downloaded SVG files were checked for scripts and external image references.

Marks identify education and internship organizations. Original marks retain their owners' identity; the custom Cheyun identifier is explicitly distinguished here. No external asset hotlinks are needed at runtime.
